- **An interrupted red-first proof no longer stores its torn-down baseline as a finished leg.** A SIGINT, SIGTERM or error on the proof's main thread tears down the baseline running beside the task leg; that run's exit came back with no problem, so the leg store kept it, and every later proof at that HEAD replayed a red baseline and could not prove until HEAD moved. A torn-down run now ends with no exit code and a problem saying it was stopped, so it is never kept. A leg is also keyed on the commit its throwaway checked out rather than the HEAD read before the throwaway existed, so a HEAD that moves in between keeps nothing; and the fix leg is always run and never kept, because its linked dependencies are keyed by their plan, not their contents, and a replayed pass of it over an upgraded dependency would turn a red into `proved`.
