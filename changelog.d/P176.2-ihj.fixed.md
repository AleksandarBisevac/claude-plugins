- **A writer or reviewer session's prompt no longer arms what the owner's words arm.** That session's prompt is its brief, which the plan and the model wrote, but its payload names no agent, so `_config.owner_prompt` read it as the owner's: a task description carrying `#no-plan` armed the plan-first bypass, `#approve-high-risk` armed the standing high-risk approval, `#release-with-bugs` armed the release bypass, and the prompt hook parsed a verb out of it. `owner_prompt` now answers nothing when the runner's writer-session mark is set, and every keyword reader goes through it. The sweep also drops that mark from what a suite inherits, so a sweep run from inside a writer session no longer turns the hooks' orchestrator cases red.
