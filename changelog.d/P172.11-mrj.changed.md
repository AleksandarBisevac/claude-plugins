- **A runner spelled with the recorded `{paths}` slot takes only the kinds of suite its collection rule reads.** The writer's and the executor's brief used to read the plan's recorded runner spelling as a runner that takes a suite of any extension, so with a task adding a `.mjs` suite the brief counted the bare sweep as running it, or told the writer to run the sweep over it, which the sweep refuses. A spelled runner now takes the kinds `_runner_collects` names for it (the project's sweep and `pytest` read `.py`, `vitest` and `jest` read JavaScript and TypeScript); a suite of another kind is named with the reason no command could be given, and a runner whose collection rule is not known is handed no suite, with a line saying its kind is not known.
