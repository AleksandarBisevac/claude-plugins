- **A writer or reviewer session the runner starts is refused what a subagent is refused.** `run-agent-session.py` marks the session it starts with `AUDIT_WRITER_SESSION` set to its role, and the hooks ask one new question of that mark, `_config.writer_role`. A top-level `claude -p` session carries no `agent_id`, so until now its edits to the plan passed as the orchestrator's; now `require-plan` refuses it the manifest and its shards and gives it the stop-and-report plan-gate refusal, and `guard-secrets-read` refuses its shell writes to the plan, exactly as for a subagent. The mark can only add restriction: any value counts, a blank one counts as none, and an orchestrator session with no mark gets every verdict it got before.
