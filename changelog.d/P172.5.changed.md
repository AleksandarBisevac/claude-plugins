- **A red declared step's base is measured over the suites the red named, not the whole step.** When a task gate's step is the bare form of the plan's recorded spelling (the runner called with no path) and its runner named the failing suites, `run-test-gate.py --base-of` runs that spelling over those suites alone and records it under the per-suite base step's name; the reading then answers the step suite by suite, each suite by the base step that ran it, and a base never answers for a suite it did not run. A red naming no suite, naming more than its row carries, or naming a suite that is not a file of the base tree by its repository-relative path is still measured whole. A reading that took several base runs names them all, and a suite is charged to the task only when every one of them carried the recorder's writes the red's tree held.
