- **A task's second gate no longer re-reads every Python file to pick its affected suites.** The gathering now keeps what it reads of each Python source - whether it parses, its imports, and what each test runner's cases walk - in the selection store under git's own directory, keyed by the file's content and by the code that read it, and the next gathering reads only the files whose content changed. A runner's walk is kept with every module and name it was followed through, so editing a helper a runner calls reads that runner again, and a kept reading is used only when its digests are the sources' own, so the selection equals a cold one. The whole-answer key is unchanged.
