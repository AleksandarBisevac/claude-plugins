- **A base measured suite by suite is recorded under its own step name and reused suite by suite.** A base run over the suites a red named is kept as one step of the declared entry's name joined to the suites it ran, so it answers a later red for exactly those suites and never for one it did not run, and two base runs at one commit over different suites together answer a red naming both; a whole-step base still answers every suite, and a red naming no suite is still measured whole.
