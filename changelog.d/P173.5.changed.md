- **The red-first helper can leave the fix run to the task gate.** `stamp-verification.py red --fix-by-gate` runs the baseline and the task's run and makes no fix run; a red is still `proved`, and its block adds `fixLeg: task-gate` with a basis saying no fix run was made there. Such a block is filed only with the green gate run that showed the fix bound to it (`fixLegRunId`); an executor return carrying one without it is refused. Without the flag nothing changes.
