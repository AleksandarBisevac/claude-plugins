- **A comment-only edit to a task's tests no longer reruns the red-first task leg.** The task leg runs HEAD's implementation under the task's test files, so `stamp-verification.py red` now keys it on those files' code - a Python file's tokens without comments and blank lines; any other file, or one that does not tokenize, by its bytes - and replays it after an edit that touched only comments. The fix leg and every lock stay on bytes. The proof's basis names the code digest it was keyed on and what that reading cannot see (a test reading its own comments or line numbers), the payload carries it as `testCodeDigest`, and the drive's re-proof note says when the test files changed outside their code (comments only) and whether the task leg was replayed.
