- **A writer's red-first proof binds to the task gate only when the gate ran the proof's own tests, and a fix leg that cannot prove is filed rather than stranded.** On the writer path the gate now stands for the proof's fix leg only when its green run holds a step of the proof's own command that passed over at least as many cases as the proof's task run collected; any other run has the helper make the fix leg, as before. When that fix leg cannot prove, for example because its run timed out, the return is filed as `could-not-prove` with the reason. Previously such a return was sent back to the writer and never filed. A bound proof's basis now says what the gate run showed, and it no longer carries an implementation digest from a round that no fix run read.
