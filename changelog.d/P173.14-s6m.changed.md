- **A gate step that runs the selftest sweep records the cases the sweep printed, so a writer's red-first proof can bind to it.** The step in the run's ledger row and record now carries `sweepCases`: the total off the sweep's `files ok, N cases` summary line, and each file's own count off its `ok` line or, for a file the sweep graded red, off the suite's own tally the sweep reprints. A file whose count the sweep did not print (its quiet form prints no line for a passing file) is left out rather than given a share of the total, and the list is cut at the row's path bound with `filesDropped` saying how many files were left out. The step's `ran` stays empty for a sweep and its verdict is unchanged; the drive reads these counts only to decide whether the task gate's run can stand for a proof's fix run.
