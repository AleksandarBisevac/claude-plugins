- **A red gate run names a step that took more than twice its last recorded time.** When a run goes red, each step is compared with the same step in the previous run of the same subject that reached a verdict - the task's own record for a task run, the phase's own gate for a phase run - and a step over twice that time prints `step <name> took <s> s, <k>x its last recorded <s'> s` under the `GATE RED` line. The reading is carried on the run's record and ledger row as `stepTime` (a `slower`, `within` or `no-basis` word, the steps named with both durations, and the basis); a run with no earlier record to compare with says the comparison has no basis rather than printing nothing, and a green run prints and carries nothing. A cancelled or killed earlier run, a step copied from an earlier run and a step whose last time was under a millisecond are not compared. The record shape is outside the compatibility promise.
