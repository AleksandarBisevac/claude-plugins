## What is not here

Planning, the backlog and market/competitive analysis live in a **private** repository,
`AleksandarBisevac/quality-gates-internal`. They were moved out on 2026-08-08.

That is a deliberate split rather than an omission. Documents that help you evaluate or operate
the plugin belong here — including `SECURITY.md`, which states plainly what the guards do _not_
guarantee, and the concurrency report above, which documents how this tool can corrupt state.
Publishing that is the point of a security-adjacent tool. A list of unfixed defects and an
unshipped roadmap are a different thing: they are for whoever is building the plugin, not for
whoever is deciding whether to install it.

Earlier revisions of the moved files remain in this repository's history. It was **not** rewritten
— the marketplace listing pins a commit SHA, and a force-push would break it along with every
existing clone.
